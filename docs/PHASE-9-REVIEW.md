Redis yayını PostgreSQL transaction'ının parçası değildir: yayın sonrası rollback/çökme aynı `event_id` ile tekrar yayın üretebilir. Tam bir kez teslim garantisi yoktur; istemci event ID ve aggregate sequence ile idempotent işler. Sağlayıcı kabulü fiziksel cihaz teslimi değildir.

Gerçek tarayıcı koşusunda bulunan ek nedenler de düzeltildi: SignalR negotiate isteklerine güncel CSRF cookie değeri eklenir; dispose edilmiş hub üzerinden `Context` okumayan transport abort callback'i kullanılır. Müşteri menüsü yeni snapshot'ı uygular; iptal edilmiş ilk HTTP isteği veya önceki şubenin geç yanıtı güncel ekranı geri alamaz. `DigitalMenuView`, `CustomerRealtimeSnapshotScope` ve cursor scope testleri bu yarışları korur. `StaffEndpoints` durum değişikliğinde doğrulanmış JWT tenant kapsamını servise aktarır; servis mevcut rol/branch kontrollerini sürdürür.

HTTP sync `SHARE` kilidi tüm tenant writer'larını kısa süre bekletebilir. Bu, XID sırasına dayanmayan doğruluk karşılığındaki maliyettir; kilit alınamazsa hata/retry uygulanır, güvensiz cursor dönülmez. Üretim yükü altında kilit bekleme süresi ayrıca izlenmelidir.

Yeni unique indeks öncesinde mevcut duplicate teslimatlar varsa migration durur; otomatik veri silmez. Önce olay/cihaz kayıtları incelenip ayrı bir işletim işlemiyle uzlaştırılmalıdır. Rollback API rolüne global claim yetkisini yeniden vermez.
